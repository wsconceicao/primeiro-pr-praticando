# Calculator

A tiny calculator library used to practice the pull request workflow.

## Usage

```python
from calculator import add, subtract, multiply, divide

add(2, 3)       # 5
subtract(5, 3)  # 2
multiply(4, 3)  # 12
divide(10, 2)   # 5.0
```

## Running tests

```bash
python -m unittest test_calculator.py
```
